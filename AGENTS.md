# Skills

This repo contains a number of agent skills:

- [`grill-with-specs`](skills/grill-with-specs/) - Interviews the user relentlessly to update the spec and glossary.
- [`prior-art`](skills/prior-art/) - Finds how a problem has been solved before and chooses a design from it.
- [`spec-review`](skills/spec-review/) - Reviews changes to a product spec.
- [`spec-writing`](skills/spec-writing/) - Writes or edits a product spec.
- [`stabilize-spec`](skills/stabilize-spec/) - Finds why a product spec keeps needing clarification and proposes rules and redesigns that make it stable.
