# Skills

Agent skills by Johan Tibell.

## Install

```sh
npx skills add tibbe/skills
```

To install a single skill:

```sh
npx skills add tibbe/skills --skill software-design
```

## Skills

- [**software-design**](skills/software-design/SKILL.md): Design the code
  before changing it. Use before implementing a feature or fixing a bug.
- [**interface-doc-review**](skills/interface-doc-review/SKILL.md): Review the
  interface documentation in the changes since a fixed point (commit, branch,
  tag, or merge-base).
