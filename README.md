# Skills

## Install

```sh
npx skills add tibbe/skills
```

## Skills

- [**prior-art**](skills/prior-art/SKILL.md): Find how the problem has been
  solved before, and choose a design from it. Use before implementing a feature
  or fixing a bug, and before deciding what a product does.
- [**stabilize-spec**](skills/stabilize-spec/SKILL.md): Find why a product spec
  keeps needing clarification, and propose the rules and redesigns that would
  make it stable.
